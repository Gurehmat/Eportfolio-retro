AI Lesson Coach

Enterprise AI coaching chatbot I built with a 3-person team (as team lead) for a real Workplace Edge client, an eLearning company. It answers only from the client's own lesson content, a closed system with no vector database and no RAG. Frontend is React 18 + TypeScript + Vite + Tailwind on Vercel, the API is Node + Express + TypeScript on Railway, and the database is Turso (libSQL) via Prisma using the @prisma/adapter-libsql adapter. Model is Gemini 2.5 Flash.

  • Grounded the assistant in the client's own material by injecting all ~20 lesson plans directly into Gemini 2.5 Flash's ~1M-token context, so it stays a closed system with no vector database or RAG.
  • Built an intent detection layer that routes each learner message into one of 4 categories and adapts the response to their current module.
  • Added a safety layer that keeps it on-topic, with PII stripping and HR/crisis escalation.
  • Embedded the chatbot inside the LearnWorlds LMS through a custom SCORM package so it renders right inside existing courses.
